# Принтанит Outdoor

Локальный редизайн **только главной страницы** [outdoor.printanit.ru](https://outdoor.printanit.ru/).

## Открыть

Без установки зависимостей:

```sh
python3 scripts/serve.py
```

Откройте http://127.0.0.1:4173. Также можно открыть `index.html` непосредственно в браузере.

## Что сделано

- Компактная шапка, спокойный фон, новая типографика Manrope с кириллицей.
- Крупный первый экран без параллакса, размытия и непрерывных анимаций.
- Локальные WebP из исходных фотографий главной. Исходные JPEG сохранены.
- Портфолио из пяти реальных проектов с фильтром и просмотром фотографий.
- Блоки производства, этапов работы, акций и контактов.
- Адаптивная вёрстка, мобильное меню, клавиатурная навигация, поддержка reduced motion.
- Кнопки заявки открывают форму, которая **подготавливает письмо** в почтовой программе. Автоматической отправки нет; для боевого сайта потребуется подключение к WordPress или серверному обработчику.

## Границы

Другие страницы не открывались и не скачивались. Ссылки на каталог, публикации, акции и исходную галерею ведут на действующий сайт. Полный WordPress/PHP-код недоступен из открытого фронтенда и сюда не включён. Счётчики, CAPTCHA, плагины и сторонние скрипты в локальном макете не запускаются.

Тестовый материал акции из исходника не перенесён в публичный текст макета: вместо него стоит ссылка на раздел акций. Показатели и контакты взяты с главной; редакционные утверждения перед боевым внедрением нужно подтвердить у компании.

## Файлы

- `index.html`, `styles.css`, `app.js` — редактируемая страница.
- `assets/` — все используемые изображения и шрифты; сеть для их загрузки не нужна.
- `reference/` — сохранённые исходники главной и снимки для сравнения.
- `DESIGN.md` — принципы оформления и палитра.
- `scripts/serve.py` — локальный сервер без зависимостей.

Исходник сохранён 18 октября 2026 года. Шрифт Manrope распространяется по SIL Open Font License, текст лицензии в `assets/fonts/OFL.txt`.

## Проверка

Проверено во встроенном браузере: ширины 320, 390, 768, 1024, 1280 и 1440 px без горизонтального переполнения; мобильное меню; фильтры проектов; просмотр фотографии и переход к заявке; закрытие окон по Escape; проверка обязательных полей. Все изображения загружаются локально, ошибок и предупреждений в консоли нет. Дополнительно проверены вложенность HTML, локальные ссылки, кириллица шрифтов и синтаксис JavaScript.
